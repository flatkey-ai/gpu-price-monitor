# 返回数据口径与契约设计

本文件描述目标接口的数据语义，公共采集 API 和全部返回类型尚未实现。字段名在接口稳定前可能调整，不能将本文当作当前可调用接口。库不实现数据库、历史序列或迁移。

## 请求与结果

计划 API 为 `collect_prices(providers, filters)`。请求来源列表、筛选和请求选项；认证由调用方环境提供。结果应包含结构化报价、容量信息（来源支持时）、各来源执行状态、实际应用筛选和错误。

| 逻辑记录 | 内容 |
| --- | --- |
| 采集请求 | 来源、筛选条件、超时与重试选项 |
| 报价 | 原始价格、资源配置、地理与账号范围、时间、来源 |
| 容量信息 | SKU、地区、容量状态及采样时间；与价格范围分开 |
| 筛选应用情况 | 请求值、应用值、是否支持、是否验证及原因 |
| 来源结果 | 来源、开始结束时间、成功 / 部分成功 / 失败状态、错误及数量 |

报价为零必须有来源明确证据；空结果也必须说明是无匹配、询价、缺货、未支持筛选还是采集失败。某来源失败不应删除其他来源的成功结果。格式或鉴权全局配置无效与运行中局部失败应区分。

## 报价条件

需要表达的规范化条件包括：

```text
provider / product_type / source_site / sales_country /
compute_country / region / zone / raw_sku /
gpu_model / gpu_variant / vram_gib / gpu_count / allocation_type /
cpu / memory_gib / disks / network_profile /
billing_mode / commitment / currency / tax_scope /
account_scope / discount_conditions
```

无法确定的值为 `null` 或明确的 `unspecified`，不能由币种、网页语言或访问 IP 猜测服务国家。保留厂商原始 SKU 和标签，标准化 GPU 名称不替代原始信息。

账号报价范围区分公开目录、认证目录、账号询价和合同价。认证目录不自动等于账号专属价，也不自动具有公开发布许可。

价格地理范围另行表示地域、可用区、全球或未说明，不与账号范围混用。Lambda 等来源可能返回一份目录价和多个可用容量地区：二者分别返回，不凭容量列表生成逐地区价格。

## 金额、时间与来源

| 字段语义 | 规则 |
| --- | --- |
| 原始金额 | 十进制字符串，避免二进制浮点误差；询价项金额为空 |
| 币种及原始单位 | 保留来源币种、每实例 / 每 GPU、小时 / 月 / 年等口径 |
| 价格基础 | 区分整实例、GPU 分项、挂牌单卡和“低至”起价 |
| 包含项 | GPU、CPU、内存、磁盘、网络、税费及相关条件 |
| 派生单卡小时价 | 仅卡数、周期和配置明确时返回，同时提供公式及假设 |
| 采集时间 | 带时区时间；表示本次观测时刻 |
| 生效起止时间 | 仅采用来源可确认的值，未知时为空 |
| 来源 | URL、厂商原始 SKU、解析器版本及必要的非敏感来源说明 |
| 报价状态 | 确定报价、需询价、不可用、待核查等状态 |
| 可用性 | 有容量、无容量、未知；与是否存在价格分别表达 |

价格有效期与采集时刻不同。文档可能同时包含历史价格和未来生效价格，解析器必须区分。没有历史采样时不能还原旧价格。

换汇、月年价格的业务等效计算、历史去重、涨跌分析和数据过期判断由调用方实现。返回值不混入调用方缓存的旧报价。

## 筛选应用情况

每个请求筛选应返回适用来源、请求值、来源实际使用或返回的值以及状态。状态应能区分已应用并验证、对返回集合本地筛选、来源不支持、无法验证和无匹配。

例如，请求某地区时，来源仅公布全球价，不能伪装为已得到该地区独立报价。平台支持地区选择时，页面或 API 的实际返回地区必须核对；回退默认地区不能默认为请求成功。

## 错误与安全

计划区分配置、凭据缺失、认证、限速、网络超时、业务接口失败、页面结构变化、解析单位不明、未支持筛选等错误。错误应带来源、非敏感说明和可重试性；不得回显 API key、Cookie、签名或原始账号响应。

库仅提取与报价有关的必要字段。原始控制台响应、浏览器会话、账号标识及调用方上传信息不属于标准返回数据。
