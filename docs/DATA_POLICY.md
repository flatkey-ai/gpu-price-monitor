# 数据发布说明

代码采用 Apache-2.0。该许可证仅覆盖本项目中有权许可的代码和文档，不授予第三方网页、截图、商标、价格数据或账号内容的额外权利。

公开导出需通过字段白名单，并确认来源及发布范围。账号专属报价、合同价、优惠身份、控制台响应、完整截图与登录状态默认仅保存在私有环境。

凭据、Cookie、访问密钥、签名和 SSH 等访问数据不得进入公开数据集、日志或工件。采集器应尽早丢弃无关敏感字段，不保存整份账号响应。

公开记录应保留平台、来源链接、采集时间、价格生效日期、币种、单位、价格适用范围及条件。缺少条件的值不能包装为确定、可即时购买的报价。

采用限速和缓存，遵循来源的访问及使用规则；访问受限时记录状态并处理授权，不绕过访问控制。
