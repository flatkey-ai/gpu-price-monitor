# 返回数据与再使用说明

代码采用 Apache-2.0。该许可证仅覆盖本项目中有权许可的代码和文档，不授予第三方网页、截图、商标、价格数据或账号内容的额外权利。

## 库与调用方的职责

库只抓取并返回结构化报价，不内置数据上传、公开数据集、数据库或发布服务。调用方决定数据去向、保留期限、上传认证、访问权限和再发布范围，并按来源条款与自己的授权处理数据。

账号专属报价、合同价、优惠身份及认证目录不能因为通过开源库返回就视为可公开发布。调用方如需公开数据，应核对来源许可并采用字段白名单。库不自动把私有报价上传到 Flatkey 或其他服务。

## 运行时不依赖 Codex 或大模型

采集由普通 Python 程序直接请求供应商 HTTP 接口；没有合适价格接口时，由固定规则解析官方 HTML 或通过本地 Playwright / Chromium 读取 DOM。运行时无需 Codex、ChatGPT、大模型 API 或人工阅读页面，也不会让模型推测价格。API 与网页来源分别标明；网页解析不能标成 API 报价，结构变化或校验失败返回错误。

`GPU_PRICE_MONITOR_SOURCE_POLICY=configured` 保留显式来源配置；`api_preferred` 优先使用可用接口，未选中合适接口时才使用程序化网页来源；`api_only` 拒绝 HTML / DOM 来源。已经选中的 API 如认证、请求或解析失败，不静默回退网页。接口返回已有资源价格、月套餐或地区库存，也不能据此宣称取得全市场各地区的每 GPU 小时报价。

## 最小必要数据

返回报价应保留平台、来源链接、采集时间、生效日期、币种、单位、资源配置、报价适用范围和相关条件。未知或未验证的条件明确标识，不能包装为确定且可即时购买的报价。

凭据、Cookie、访问密钥、签名、浏览器状态、SSH 访问数据和无关账号字段不得进入标准返回、日志或工件。采集器尽早丢弃无关敏感字段，不直接返回整份控制台响应。

贡献测试仅保存脱敏最小样本。需要浏览器会话时，返回其认证状态而不是会话内容；公开配置示例仅引用本地会话路径，不包含会话本身。

## 来源访问

采用合理超时、限速和有限重试，遵循来源的访问及使用规则。访问受限时返回可识别错误并处理授权，不绕过验证码或访问控制。

只使用只读价格、规格及容量接口；不得为获得报价创建、启动或购买收费实例。调用方对返回值进行存储、上传、比较或展示时，应保留来源与价格口径，避免把 GPU 分项、起价或询价当作确定整机价。


## 比较表与审计记录

0.11.0 默认 10 列 CSV 只纳入国家与 region 已核实的实际每 GPU 小时数值报价。位置不完整、仅覆盖、起步价、GPU 组件、月包、询价及明确不可用项保留在 JSON / `profile="full"` 审计记录中，不混入比较表；月价不按 720 小时折成小时价。缺少位置不证明全球统一价。普通 / 会员、Spot、云档位、税费与账号适用条件仍须保留，比较资格不代表库存或所有账号均可购买。

Nebius 当前地区 Spot 价来自官方无需认证的只读 API，价格生效时间与本次观察时间分别记录；截图和历史图表仅说明当时情况，不替代当前报价或作为硬编码回退。
