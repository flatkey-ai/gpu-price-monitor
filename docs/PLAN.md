# GPU 云算力价格采集库实施方案

方案日期：2026-10-15。当前为初始化版本，尚未实现实时采集和公共采集接口。

## 目标与边界

交付一个任何使用者都可以通过自己的环境变量和筛选配置调用的开源库：抓取 GPU 云算力租赁价格，校验报价条件，返回结构化结果。

本库负责来源访问、API 认证、必要浏览器交互、筛选核对、价格解析、单位校验及每来源错误。首期来源为 Nebius、Crusoe、Lambda、UCloud、AutoDL。模型 Token、托管推理和硬件销售不进入首期报价集合。

调用方负责定时运行、部署、存储与历史、上传、汇率换算、价格比较、告警、看板和数据发布。Flatkey 的采集运行器也通过这个公共接口使用库，在私有系统中上传和处理返回值。库不持有业务上传地址、上传密钥或组织专属逻辑。

## 调用和返回设计

计划提供 Python API `collect_prices(providers, filters)`，以及 `collect` CLI。两者尚未实现；现有 CLI 仅支持状态与配置检查。

调用流程：

```text
调用方注入 env、指定来源及筛选
→ 配置校验
→ 对应适配器执行规格发现及只读报价采集
→ 校验筛选、单位与价格适用条件
→ 返回结构化报价与每来源结果
→ 调用方决定存储、上传或其他业务处理
```

API 返回可序列化结果；CLI 将结果 JSON 写至 stdout，将日志写至 stderr，便于其他语言和运行器调用。凭据缺失、认证失败、限速、网络故障、页面变更、未支持筛选及单位不明需有结构化错误分类。一个来源失败不应丢弃其他来源成功的报价。

输出保留原币金额、原始单位、资源配置、报价身份、服务位置及价格适用地区、采集和生效时间、来源、筛选应用情况。详细字段和未知值规则见 [数据契约](DATA_MODEL.md)。

## 配置和筛选

非敏感采集配置放在 `configs/collect.example.json`：来源、地区和规格筛选、请求选项。示例厂商全部关闭，避免检查配置时发起请求。凭据从进程环境读取，由调用方注入；当前不自动读取 `.env` 文件。

环境变量包括来源列表、超时、重试，以及各平台凭据。具体名称和默认值见 [接入说明](DEPLOYMENT.md)。采集配置不得包含调度时间、数据库、上传 URL、Webhook 或看板参数。

筛选至少考虑平台、产品线、销售站点及国家、服务国家、地域、可用区、SKU、GPU 型号与版本、显存、卡数、CPU、内存、磁盘、计费方式、承诺期限、币种、税费及报价身份。只发现和查询厂商实际支持的组合，不生成不存在的地区和规格。

API 显式传入地区和完整配置；网页确认实际选中状态。返回中分别记录请求的筛选和实际应用情况。平台未细分地区时保留原范围，不能把该报价复制成多个地区的独立价格；无法满足地区筛选时应明确返回不支持或无法验证。

## 来源策略

| 平台 | 采集方式 | 必须保留的边界 |
| --- | --- | --- |
| Nebius | 官方公开计价文档优先，认证估价 API 补充 | 生效日期、币种、GPU / CPU / RAM 分项、起价与确定价 |
| Crusoe | 官网 GPU instances 价格区块 | GPU 实例与推理服务分开；询价金额为空，购买条件不确定时明确标注 |
| Lambda | 官方实例目录 API | 整实例价格和 GPU 数量；容量地区独立于价格范围 |
| UCloud | 可售配置发现，再按完整配置询价 | 地区、CPU、内存、磁盘、计费方式；校验业务成功码 |
| AutoDL | 授权市场页面，API 辅助 | 实际选中的筛选；已有资源报价及库存接口的覆盖限制 |

来源优先级为官方价格 API、官方公开 HTML 或结构化数据、必要时的授权浏览器。采用确定的解析规则；无法确认配置、单位或页面结构时返回错误或待核查状态，不猜测数值。官方核查链接见 [平台说明](PROVIDERS.md)。

## 价格规则

保留原始十进制金额、币种、单位、计费周期、最低消费、资源包含项和优惠条件。按需、抢占式、包月、包年分别描述，不由库合并成一个价格。

整实例价可在卡数和计费单位明确时返回带公式的套餐分摊单卡小时价。GPU 分项不能代表整机总成本。周期或折算条件不充分时只返回原始价格，不假设每月小时数。跨币种换算和历史涨跌比较由调用方执行。

报价、询价、无可用容量、采集失败分别返回。采集器不把“上次价格”作为本次结果；若调用方缓存历史，应自行标明缓存或过期状态。采集到的 Spot 报价仅代表采样时刻，不代表全天最低价。

## 实施顺序

1. 完成公共数据契约、env 配置、适配器接口和结构化错误。
2. 实现 Nebius、Crusoe 公开来源，验证来源范围和筛选反馈。
3. 接入 Lambda、UCloud 认证 API，再完成 AutoDL 授权浏览器采集。
4. 提供 Python / CLI 采集入口、调用示例、安装包和版本兼容说明。

每一步以真实支持范围为准，不把未实现适配器作为可采集来源展示。账号联调只使用只读操作，不创建收费实例。

## 验收

- 调用方使用自己的 env 和筛选配置即可运行，不依赖 Flatkey 服务。
- 原币金额、卡数、单位、报价范围、采集和生效时间可追溯到官方来源。
- 国家、地区和计费条件正确应用；未应用或无法确认的筛选被显式返回。
- 地区未知不伪造，容量地区不被当作逐地区价格。
- 认证、网络、业务错误及页面变化返回结构化状态，失败不变成零元。
- 部分来源失败时保留其他成功结果，CLI JSON 不混入日志和凭据。
- 配置检查不发起真实采集；安装包和脱敏解析测试通过。

本库无需 GPU。实际运行环境、调用频率和上传基础设施由使用者自行选择，库不承诺固定采集时刻或托管服务。
