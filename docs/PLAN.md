# GPU 云算力价格采集库实施方案

方案更新：2026-10-15，版本 0.2.0。提供 Nebius / Crusoe 公开采集和 Lambda / UCloud 认证只读适配器，共用 Python API、JSON CLI。认证适配器已覆盖离线样本；当前无凭据，尚未完成真实账号报价联调。

## 目标与边界

使用者通过自己的环境变量和筛选配置调用同一个开源库，获取 GPU 云算力租赁报价及可追溯条件。

本库负责来源访问、请求超时与有限重试、确定性价格解析、筛选核对、原始单位和条件保留、结构化返回。调用方负责定时执行、部署、数据库和历史、上传、换汇、竞品比较、告警和看板。库不持有 Flatkey 上传地址或专属业务凭据。

模型 Token、托管推理和硬件销售不进入当前报价集合。公开挂牌不保证即时可购买；需询价、起价和 GPU 分项分别标识。

## 当前能力

| 来源 | 当前实现 | 限制 |
| --- | --- | --- |
| Nebius | 官方 Compute 公开计价 Markdown，解析资源分项、币种、地区和生效日期 | GPU 分项不代表整机总成本；认证估价 API 未实现 |
| Crusoe | 官网 GPU instances HTML 价格区块 | 排除托管推理价格；询价金额为空；未公布逐地区价格 |
| Lambda | 认证实例目录 API | 需调用方 API key；实例原价按卡数分摊；容量地区独立于报价范围，未实测认证报价 |
| UCloud | 按显式完整 target 执行 `GetUHostInstancePrice` | 需公私钥及目标配置；仅 Dynamic 完整 GPU 实例；不自动发现可售规格，未实测认证报价 |
| AutoDL | 未实现，返回 `not_implemented` | 后续授权网页筛选和必要 API 辅助 |

官方核查链接见 [平台说明](PROVIDERS.md)。当前两个公开来源无需凭据，不需要创建或租用 GPU 资源。

## 使用路径

Python API `collect_prices(providers, filters, settings=...)` 返回可 JSON 序列化的字典；`collect` CLI 将相同类型结果写到 stdout，日志写 stderr。

```text
调用方 env / 来源 / 筛选
→ 配置检查
→ 官方来源请求与解析
→ 筛选、时间和单位校验
→ prices + 每来源状态 / 筛选反馈 / 错误
→ 调用方自行处理
```

结果包含 `schema_version=1`、`status`、UTC `collected_at`、`prices` 和 `provider_results`。全部成功、部分失败、全部失败分别表达；无匹配不等于请求失败。CLI 返回码用于进程编排，详细情况通过每来源结果核对。见 [接入说明](DEPLOYMENT.md) 和 [数据口径](DATA_MODEL.md)。

## 地区与筛选

GPU 型号、币种和计费方式可在四个已实现来源筛选。Nebius 地区条件可核对，UCloud 可按请求 target 的地区 / 可用区筛选。Crusoe 和 Lambda 请求地区时返回 `unsupported_filter`；Lambda 容量地区不等于价格地区。卡数筛选支持 Lambda / UCloud。四家均不从地区名猜测国家映射，国家条件无法可靠应用时返回结构化错误。

来源未知地区保留未知值，不能由币种、网页语言、IP 或地区库存推断价格范围。后续接入 API / 授权网页时，显式传入地区和完整配置，并核对实际返回或选中条件。

配置支持字段与来源实际支持能力分别校验；不能因字段格式合法就静默忽略无法应用的筛选。原始请求、实际应用情况和失败原因需要能由调用方获知。

## 价格口径

保留原始十进制金额、币种、单位、计费方式、资源包含项和优惠条件，以及来源、采集时间和生效日期。确定报价、起价、需询价、不可用和采集失败分别处理，不用零元表示失败。

GPU 分项不代表整实例成本。Lambda / UCloud 的单卡值为整实例小时成本除以卡数，保留整实例原价和资源配置。卡数、周期和配置不充分时，不计算单卡小时价或假设每月小时数。跨币种换算、历史去重和涨跌比较由调用方执行。返回值不混入旧缓存；采样 Spot 价格不代表全天最低值。

## 后续顺序

1. 配置调用方凭据后，对 Lambda 和 UCloud 开展最小范围真实只读联调；尚未联调前仅声明离线验证。
2. 持续完善公开来源解析样本、认证错误覆盖、价格变更兼容和安装包。
3. 补充 UCloud 可售配置发现，当前询价 target 不构成可售证明。
4. 实现 AutoDL 授权市场页面与筛选确认；会话和账号内容最小化处理。
5. 根据来源证据扩展国家映射和更多实例规格 / 计费方式。

未实现来源不接收成“成功但没有价格”，不使用示例结果冒充实时价格。所有认证联调仅使用只读接口，不创建或购买实例。

## 验收

- 使用者无需 Flatkey 服务即可运行两个公开来源采集。
- JSON 可供其他程序消费；部分失败仍保留成功报价并给出错误。
- 价格、单位、资源分项、生效时间和范围可追溯到官方来源。
- 已支持筛选确实应用；未知地区和不支持条件不伪造。
- 解析器通过脱敏离线样本验证；在线核查记录真实来源、时间、筛选和数量。
- 凭据不进入返回或日志；配置检查不联网。

调用频率、上传与存储由使用者决定，本库不承诺固定采集时刻或托管服务。
