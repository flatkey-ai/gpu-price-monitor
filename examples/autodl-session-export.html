保存 AutoDL 登录状态

在你自己的 Chrome 中操作，把登录状态保存成一个本地 JSON 文件，供采集程序使用。无需再登录专用窗口。

  1. 将下面的链接拖到 Chrome 书签栏。书签栏未显示时，按 ⌘ Shift B（Windows：Ctrl Shift B）。

    保存 AutoDL 会话到本地

    这里用于拖成书签，不是在当前页面点击运行。
  2. 切回你已登录的 AutoDL 官网市场，点击刚添加的书签。
  3. 浏览器将下载 autodl.storage-state.json。将这个文件留在本机，再交给本地导入脚本。

这个文件含登录凭据，请勿上传、发给他人或提交 Git。工具只保存该官网的 token，不读取 Cookie 或个人资料，不发网络请求，不租用资源。完成后可删除书签。

查看全部书签代码
(function () {
  'use strict';
  try {
    if (window.top !== window.self || location.origin !== 'https://www.autodl.com' || location.pathname !== '/market/list') {
      alert('请先在 https://www.autodl.com/market/list 登录并打开市场，再点击这个书签。');
      return;
    }
    const token = localStorage.getItem('token');
    if (typeof token !== 'string' || token.length === 0 || token.length > 65536 || /[\s\u0000-\u001f\u007f]/.test(token)) {
      alert('当前官网页面没有可用的登录状态，请先完成登录。');
      return;
    }
    const state = {cookies: [], origins: [{origin: 'https://www.autodl.com', localStorage: [{name: 'token', value: token}]}]};
    const url = URL.createObjectURL(new Blob([JSON.stringify(state)], {type: 'application/json;charset=utf-8'}));
    const link = document.createElement('a');
    link.href = url;
    link.download = 'autodl.storage-state.json';
    document.body.appendChild(link);
    link.click();
    link.remove();
    setTimeout(function () { URL.revokeObjectURL(url); }, 1000);
  } catch (_) {
    alert('本地保存未完成。请确认已在 AutoDL 官网市场登录；不要粘贴或分享登录凭据。');
  }
})();
